# Local eSIMs for travellers

TheeSimWorld runs travel eSIM stores. Each one sells prepaid eSIMs that run on the destination's own mobile networks, like a SIM card bought at the airport, but installed from a QR code before the trip. Every plan names its network before you pay.

## What makes an eSIM local

A local eSIM uses the destination's own operator as its home network: the phone shows that country's network code and a local access point (APN), and data does not travel through another country first. A plan is sold as local only when its home network and APN are the destination's own, and each plan page names its network.
